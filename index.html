2. Key App Features & Functionality

Status Saver provides users with simple utility tools for saving and managing status media:

  • Dual Support: View and save status photos and HD videos from both standard WhatsApp and WhatsApp Business.
  • Built-in Media Viewer: Full-screen high-definition video player and interactive image viewer with pinch-to-zoom capabilities.
  • One-Tap Save & Repost: Save media directly to your phone's Gallery (Pictures/Movies) or repost/share directly with friends without saving.
  • Batch / Multi-Select Management: Select multiple media files to save or remove at once.
  • Favorites Organizer: Mark and manage frequently viewed or favorite media items locally.
  • 100% Offline Core Functionality: All status detection and media processing happen strictly locally on your Android device.

3. Device Permissions & How They Are Used

To provide its core functionality, Status Saver requests specific Android permissions. We only request permissions strictly required to deliver the advertised features:

  • Storage Access / Storage Access Framework (SAF):
    Used to locate and read the WhatsApp status folder (.Statuses) after the user grants explicit folder access in accordance with Android's Scoped Storage (Android 11, 12, 13, 14, and 15).
  • READ_MEDIA_IMAGES & READ_MEDIA_VIDEO (Android 13+):
    Used solely to read and display downloaded media items in the app's 'Saved' and 'Favorites' tabs.
  • READ_EXTERNAL_STORAGE & WRITE_EXTERNAL_STORAGE (Android 10 and below):
    Used to read and write saved media files to the public Pictures/StatusSaver and Movies/StatusSaver directories.
  • INTERNET & ACCESS_NETWORK_STATE:
    Used to serve advertising via Google AdMob and check network connectivity for ad loading.
